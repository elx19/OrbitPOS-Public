These previews define the shared visual language for the 2.1 redesign:

- `login-reference.png`: access screen, brand panel and license status.
- `wizard-reference.png`: first-run configuration wizard.
- `dashboard-reference.png`: business summary, quick sale and inventory alerts.
- `pos-reference.png`: rapid sale, cart and payment flow.
- `products-reference.png`: catalog, stock levels and category filters.
- `purchases-reference.png`: supplier order and inventory receipt flow.
- `reports-reference.png`: sales analytics and category/payment breakdowns.

The implementation must keep the same hierarchy: deep navy navigation, emerald primary actions, white cards, slate typography, generous spacing and clear labels for colmado, carnicería and embutidos.

- `cash-reference.png`: apertura, movimientos y arqueo de caja.
- `customers-reference.png`: clientes, saldos y estado de cuenta.
- `suppliers-reference.png`: proveedores y órdenes de compra.
- `discounts-reference.png`: promociones, vigencia y vista previa.
- `credits-reference.png`: créditos, vencimientos y abonos.
- `returns-reference.png`: devoluciones, reingreso a inventario y reembolso.
- `quotes-reference.png`: cotizaciones y conversión a venta.
- `notifications-reference.png`: alertas de inventario, caja y licencia.
- `users-reference.png`: usuarios, roles y permisos.
- `config-reference.png`: configuración del negocio y estado del sistema.
- `help-reference.png`: centro de ayuda y soporte.
- `license-reference.png`: activación, historial y diagnóstico de licencia.
