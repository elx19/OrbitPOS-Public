# OrbitPOS 2.1.0-alpha.72

## Productos e inventario alineado a la referencia

- Se reemplazó la composición genérica por una vista operativa con título, búsqueda, filtros por categoría y tabla de productos.
- La tabla muestra imágenes reales del catálogo, código, categoría, stock, mínimo, costo, precio y estado.
- Se agregaron paneles de productos con bajo stock y resumen de inventario usando únicamente datos reales del negocio seleccionado.
- El alta y la edición de productos se conservaron debajo de la vista operativa, incluyendo selector de imagen, precios, unidades y control de productos por peso.
- La vista mantiene el aislamiento de categorías definido por `businessType` y el comportamiento responsive del shell.

## Verificación

- `npm run qa:ui`
- `npm run build`
- QA visual de navegador: Productos e inventario en escritorio y vista estrecha, con tabla horizontal contenida y navegación compacta.
