# OrbitPOS 2.1.0-alpha.48

## Corrección de perfil y sidebar

- Se eliminó el logo personalizado grande del pie del sidebar.
- Se eliminó el botón de cerrar sesión del sidebar.
- El logo elegido por el negocio ahora aparece en el avatar y en el menú del perfil del usuario.
- El menú del perfil incluye el nombre del negocio, el usuario, el rol, el acceso a Configuración para administradores y Cerrar sesión.
- El pie del sidebar conserva únicamente la identificación compacta de la sucursal, sin repetir el logo del negocio.
