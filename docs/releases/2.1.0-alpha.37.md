# OrbitPOS 2.1.0-alpha.37

## Objetivo

Alinear Proveedores con la referencia visual y conservar su CRUD real.

## Cambios

- Encabezado “Proveedores” con descripción y CTA “Nuevo proveedor”.
- KPIs de proveedores activos, total del directorio y selección actual.
- Directorio con búsqueda y presentación tipo tabla para empresa, contacto y estado.
- Panel de proveedor seleccionado para crear, editar, activar o desactivar y guardar notas.
- Se conservan las rutas reales de creación, edición y actualización del directorio.

## Verificación

- Build Vite completado correctamente.
- Navegador a 1920×1080 y móvil: módulo `suppliers` sin overflow horizontal.
- CTA, búsqueda y formulario CRUD presentes y conectados.
