# OrbitPOS 2.1.0-alpha.50

## Ventana y DPI sin desbordamiento

- La ventana principal inicia dentro del área de trabajo real del monitor, incluso en pantallas pequeñas.
- Al cambiar de monitor o modificar la escala del sistema, Electron ajusta la ventana restaurada para mantenerla dentro del área visible.
- Se conservan las métricas de DPI, tamaño y área de trabajo expuestas al renderer en tiempo real.

## Generador de licencias endurecido

- `keygen` ahora devuelve la huella SHA-256 de la clave pública Ed25519.
- Se añadió `fingerprint --public-key-file` para identificar la clave que debe distribuirse con el POS.
- `generate --private-key-file` puede validar `--public-key-file` y rechaza pares que no correspondan.
- La salida JSON incluye `publicKeyFingerprint` para auditorías y automatización de emisión.

## Verificación

- `node --check electron/main.js`
- `node --check electron/preload.js`
- `npm run build`
- `npm run qa:license`
- `npm run qa:production` con secreto de licenciamiento definido fuera del repositorio.

Las pruebas físicas de impresora, lector, báscula, instalación limpia, firma Authenticode y actualización siguen siendo gates para producción estable.
