# OrbitPOS 2.1.0-alpha.76

## Reportes alineados a la referencia

- Recompone Reportes con el encabezado, selector de periodo, exportación y cuatro KPI del diseño de referencia.
- Añade el gráfico de ventas netas con etiquetas, leyenda y cuadrícula visual.
- Añade las tablas de Top productos, Ventas por categoría y Métodos de pago.
- Mantiene los paneles operativos de ventas recientes, equipo, cotizaciones y stock bajo debajo de la vista principal.
- El backend entrega agrupaciones reales por categoría y método de pago dentro del perfil de negocio seleccionado.
- Las imágenes de producto se reutilizan cuando existen; los productos sin imagen conservan un fallback accesible.

## Calidad y alcance

- La versión sube a `2.1.0-alpha.76`.
- Se conserva la exclusión de firma digital y de pruebas de hardware físico del gate automático, según la decisión del operador.
- La validación final debe incluir build del instalador, QA de producción, runtime empaquetado y publicación del feed.
