# OrbitPOS 2.1.0-alpha.2

License-generator milestone.

## Included

- `license-generator` CLI with `generate`, `decode` and `verify` commands.
- Strict validation for machine ID, business name, license type and envelope integrity.
- Schema version in newly generated licenses while preserving decoding of older keys.
- JSON output and optional key-file output for support and distribution workflows.
- Isolated license QA covering generation, decoding, tamper rejection and required-field validation.

## Verification gate

- `npm run qa:license`
- `npm run build`

Production remains gated on end-to-end commercial QA with a Node-compatible native SQLite build and module-by-module runtime checks.
