# OrbitPOS 2.1.0-alpha.33

## Objetivo

Alinear el módulo de reportes con la referencia visual sin perder los datos ni las exportaciones reales.

## Cambios

- Encabezado “Reportes” y descripción orientada a supermercado, carnicería y deli.
- Indicadores principales de ventas netas, margen estimado, ticket promedio y productos vendidos.
- Gráfica diaria de ventas conectada al reporte real del periodo seleccionado.
- Se conservan filtros, actualización, exportación CSV y exportación PDF.
- El backend agrega el detalle diario y las unidades vendidas sin modificar las métricas existentes.

## Verificación

- Build Vite completado correctamente.
- Navegador a 1920×1080: módulo `reports`, gráfica visible y ausencia de overflow horizontal verificados.
- QA de producción ejecutado sobre el instalador alpha.33.
