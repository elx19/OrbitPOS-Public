# OrbitPOS 2.1.0-alpha.62

## Cambios funcionales

- El `license-generator` acepta `--public-key-file` en `decode` y `verify` para validar licencias ORB3 con una clave externa, sin depender de la clave configurada en el entorno del POS.
- La verificación externa cubre clave correcta, clave ausente o incorrecta y conserva la validación con la clave pública configurada en el paquete.
- La documentación separa claramente la emisión ORB3 recomendada de la ruta ORB2 heredada.
- Se mantiene la referencia visual del perfil: logo del negocio y cierre de sesión dentro del menú del usuario, fuera del sidebar.

## QA ejecutada

- `npm run qa:license`
- `npm run qa:ui`
- `npm run qa:display`

La construcción del instalador y la QA completa de producción deben ejecutarse antes de publicar esta alpha.
