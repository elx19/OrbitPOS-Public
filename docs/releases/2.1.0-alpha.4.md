# OrbitPOS 2.1.0-alpha.4

Complete UI reference set.

## Included

- One visual reference per principal OrbitPOS surface: login, wizard, dashboard and every registered module.
- Reference images cover POS, caja, créditos, devoluciones, cotizaciones, clientes, productos, proveedores, compras, descuentos, notificaciones, usuarios, configuración, ayuda, licencia and reportes.
- The full set lives in `docs/ui-reference` and follows one visual contract for production implementation.

## Verification gate

- `npm run qa:license`
- `npm run build`

This milestone documents the target, but it is not the stable production tag until module behavior and commercial QA are verified end to end.
