# OrbitPOS 2.1.0-alpha.15

## Diseño de acceso y configuración inicial

- Reemplaza las ilustraciones CSS de login y Configuración inicial por las dos escenas de tienda entregadas por el usuario.
- Conserva la composición de referencia: panel navy de marca, formulario blanco, acciones emerald y navegación de configuración en cinco etapas visuales.
- Procesa la ilustración del login para eliminar el fondo ajedrezado conservando el escaparate, productos frescos, carnes y vegetación.
- Mantiene los cuatro iconos transparentes de negocio en las tarjetas de tipo de negocio y los puntos promocionales del asistente.

## Verificación

- `npm run build`
- `npm run qa:license`
- `npm run qa:commercial:node22`
- `npm run qa:release`

## Alcance

Esta versión es un hito visual y funcional previo a producción. Todavía requiere la validación manual de impresora térmica, lector de códigos, báscula, instalación limpia y firma/publicación del instalador.
