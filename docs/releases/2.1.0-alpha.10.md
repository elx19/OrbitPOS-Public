# OrbitPOS 2.1.0-alpha.10

## License generator

- `verify` comprueba firma, expiración, fecha de emisión, máquina opcional y versión mínima compatible.
- Añade fechas normalizadas y rechaza sobres con rangos de fechas inválidos.
- La QA cubre licencia válida, licencia expirada y máquina diferente.

## Verificación

- `npm run qa:license`
- `npm run build`
- `npm run qa:commercial:node22`
- `npm run build:electron`
