# OrbitPOS 2.1.0-alpha.39

## Objetivo

Alinear Cotizaciones con la referencia visual manteniendo la creación, aprobación, envío, reimpresión y conversión a venta.

## Cambios

- Encabezado `Cotizaciones`, descripción y CTA `Nueva cotización`.
- KPIs separados para borradores, enviadas y convertidas a venta.
- El flujo existente de creación, clientes, productos, descuentos, pagos, WhatsApp, reimpresión y conversión permanece funcional.

## Verificación

- `npm run build`
- Preview local responsive verificado en escritorio y móvil.
- QA completo e instalador alpha.39 se ejecutan antes de cerrar esta iteración.
