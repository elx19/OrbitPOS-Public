# OrbitPOS 2.1.0-alpha.75

## Cambios

- Administradores ven todos los módulos autorizados en el lateral, sin esconderlos detrás de “Más módulos”.
- Usuarios comunes conservan únicamente los módulos autorizados por su perfil y tipo de negocio.
- Configuración inicia en la composición de Negocio/identidad de la referencia; fiscalidad y actualizaciones quedan en Operación y Actualizaciones.
- El logo del negocio y el cierre de sesión permanecen en el menú del perfil, no en el lateral.

## Verificación

- `npm run build`
- `npm run qa:ui`
- `npm run qa:display`
- `npm run qa:assets`
- `npm run qa:update-feed`
- `npm run qa:production`

La firma digital del instalador y las pruebas con impresoras, lectores, básculas o cajones físicos no forman parte del gate automático de producción.
