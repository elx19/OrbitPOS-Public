# OrbitPOS 2.1.0-alpha.57

## Contrato visual por módulo

- Se agregó `shared/ui-reference-manifest.json` como fuente única que vincula login, asistente y cada módulo de `AppShell` con su referencia visual.
- `qa:ui` comprueba que las rutas reales, las referencias PNG y el atributo `data-module` permanezcan sincronizados.
- `qa:release` también verifica los archivos declarados por el manifiesto.
- El cierre de sesión del menú de perfil usa un icono dedicado; el logo del negocio continúa limitado al perfil/identidad y no al sidebar.

## Verificación

- `npm run qa:ui` pasó todos los módulos declarados.
- `npm run build` pasó con Vite.
- La versión sigue siendo alpha: aún requiere firma Authenticode, pruebas físicas de dispositivos, instalación limpia y actualización real antes de producción estable.
