# OrbitPOS 2.1.0-alpha.44

## Objetivo

Alinear Configuración con la referencia visual manteniendo todas las herramientas administrativas del sistema.

## Cambios

- Encabezado `Configuración` y descripción de negocio.
- Navegación lateral de Negocio, Dispositivos, Tickets, Apariencia, Backups, Actualizaciones, Sucursales y Mantenimiento.
- Vista previa de identidad con logo, RNC, teléfono, dirección y mensaje del ticket.
- Estado del sistema para negocio, impresora, backup y versión.
- Se conservan detección de impresora/lector/báscula, backups, restauración, updates, sucursales, tickets y guardado.

## Verificación

- `npm run build`
- QA completo e instalador alpha.44 se ejecutan antes de cerrar esta iteración.
