# OrbitPOS 2.1.0-alpha.45

## Objetivo

Alinear Ayuda y soporte con la referencia visual sin perder las acciones operativas existentes.

## Cambios

- Hero de Ayuda y soporte con identidad OrbitPOS, imagen de tienda y buscador.
- Accesos rápidos para guía, ventas y cobros, inventario, caja y licencias.
- Ejemplos de búsqueda que filtran las áreas relacionadas.
- Bloque de soporte JRTech con manual PDF, WhatsApp, correo, versión, licencia y reconfiguración.
- Se conservan machine ID, sesión activa, apertura del manual y enlaces de soporte.

## Verificación

- `npm run build`
- QA completo e instalador alpha.45 se ejecutan antes de cerrar esta iteración.
