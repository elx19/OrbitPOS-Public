# OrbitPOS 2.1.0-alpha.71

## Inicio alineado al tablero de referencia

- Se reemplazó el panel genérico por el tablero operativo de OrbitPOS: KPIs, nueva venta, catálogo, alertas de inventario y ventas de la semana.
- El catálogo del Inicio usa los productos reales autorizados por la API y cambia sus categorías según `colmado`, `carniceria`, `embutidos` o `mixto`.
- Las acciones `Cliente`, `Limpiar`, `Escanear código de barras`, `Cobrar`, `Ver todo` y los productos del catálogo llevan al módulo funcional correspondiente.
- Los usuarios comunes ahora reciben únicamente `commonModules` del perfil de negocio; el administrador conserva el conjunto autorizado del negocio.

## Verificación

- `npm run qa:ui`
- `npm run qa:display`
- `npm run build`
- QA visual de navegador a 1280×720: tablero, navegación compacta, filtros de categorías y catálogo contextual.
