# OrbitPOS 2.1.0-alpha.29

## Objetivo

Alinear el módulo de productos e inventario con la referencia visual entregada, sin perder las operaciones reales de catálogo.

## Cambios

- Encabezado del módulo con el lenguaje visual “Productos e inventario”.
- Acción visible “Nuevo producto” con acceso directo al formulario existente.
- Panel lateral de “Productos con bajo stock” conectado al inventario real.
- Selección de un producto desde la alerta reutiliza el mismo flujo de edición.
- La alerta distingue entre inventario crítico y estado normal.

## Verificación

- Build Vite completado correctamente.
- Navegador local: botón de nuevo producto, desplazamiento al formulario y panel de bajo stock comprobados.
- QA de producción debe ejecutarse sobre el instalador alpha.29 antes de publicar.
