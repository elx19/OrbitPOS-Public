# OrbitPOS 2.1.0-alpha.24

## Cambios

- El lector serial ahora puede devolver códigos reales al POS.
- Se limpian caracteres de control STX/ETX y terminadores de los lectores.
- El POS muestra `Leer lector`, busca el código en el catálogo y agrega automáticamente el producto encontrado.
- Se conserva el flujo de lectores tipo teclado mediante el campo de búsqueda normal.
- La QA de hardware y la QA comercial cubren el estado desactivado del lector.

## Verificación

- `npm run qa:hardware`
- `npm run qa:license`
- `npm run qa:commercial:node22`
- `npm run qa:packaged`
- `npm run qa:release`

## Pendientes antes de producción

- Validar protocolos, baud rate y terminadores del lector físico del cliente.
- Validar báscula, impresora térmica y lectores físicos.
- Probar instalación limpia y actualización desde GitHub Releases.
- Firmar el instalador con Authenticode y publicar la release oficial.
