# OrbitPOS 2.1.0-alpha.63

## Hito funcional

- Las instalaciones nuevas en modo demo reciben un catálogo inicial operativo según el tipo de negocio elegido.
- Colmado, Carnicería, Embutidos/Deli y Mixto quedan separados por categorías desde el primer acceso.
- El catálogo demo no se duplica si la base de datos ya contiene productos.
- La respuesta del wizard informa cuántos productos demo fueron creados.
- La QA comercial comprueba que la demo tenga productos y que todas sus categorías sean válidas.
