# OrbitPOS 2.1.0-alpha.36

## Objetivo

Alinear Compras con la referencia visual y conservar el flujo real de recepción de inventario.

## Cambios

- Encabezado “Compras” con resumen de compras, total registrado y proveedores activos.
- Composición de dos paneles: “Nueva compra” y “Entrada de inventario”.
- Búsqueda de productos por nombre, código o categoría.
- Vista previa de productos y cantidades que se recibirán.
- “Confirmar entrada” utiliza el mismo flujo real que registra la compra y actualiza el stock.
- Historial de compras permanece disponible debajo del flujo principal.

## Verificación

- Build Vite completado correctamente.
- Navegador a 1920×1080 y móvil: módulo `purchases` sin overflow horizontal.
- Buscador y acciones “Registrar compra” / “Confirmar entrada” presentes y conectadas.
