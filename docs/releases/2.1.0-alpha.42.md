# OrbitPOS 2.1.0-alpha.42

## Objetivo

Alinear Notificaciones con la referencia visual sin alterar el centro de alertas ni sus acciones.

## Cambios

- Encabezado `Notificaciones`, descripción y acción `Marcar todas como leídas`.
- Filtros `Todas`, `No leídas`, `Inventario`, `Caja` y `Licencia` con conteos.
- Tarjetas de alerta con prioridad visual, categoría, fecha y marcado individual.
- Se conserva la actualización del contador global y el marcado masivo.

## Verificación

- `npm run build`
- Preview responsive de escritorio y móvil.
- QA completo e instalador alpha.42 se ejecutan antes de cerrar esta iteración.
