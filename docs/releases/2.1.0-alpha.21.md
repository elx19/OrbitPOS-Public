# OrbitPOS 2.1.0-alpha.21

## Cambios

- `license-generator verify` devuelve una respuesta inválida clara y código 2 también cuando la clave está corrupta o no puede descifrarse.
- Se agregó `license-generator machine-id` para obtener el identificador del equipo sin requerir el secreto privado.
- `--out` protege archivos de licencia existentes; `--force` es obligatorio para reemplazarlos.
- Las claves se escriben mediante archivo temporal y movimiento atómico, reduciendo el riesgo de archivos incompletos.
- La QA cubre claves corruptas, lectura del machine-id, protección de salida y reemplazo explícito.

## Verificación

- `npm run qa:license`
- `npm run qa:commercial:node22`
- `npm run qa:release`
