# OrbitPOS 2.1.0-alpha.19

## Entregado

- El `license-generator` acepta `--secret-file` para mantener el secreto privado fuera del historial de comandos y del repositorio.
- Se rechaza combinar `ORBITPOS_LICENSE_SECRET` con `--secret-file`, evitando firmar accidentalmente con una clave distinta.
- Los archivos de licencia generados se fuerzan a modo `0600` cuando el sistema operativo lo permite.
- `verify` devuelve código de salida `2` cuando la licencia es inválida tanto en formato JSON como en formato texto.
- QA del generador cubre archivo de secreto, lectura de `--key-file`, verificación JSON y verificación de texto.

## Verificación

- `npm run qa:license`
