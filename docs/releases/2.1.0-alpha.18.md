# OrbitPOS 2.1.0-alpha.18

## Entregado

- Integrado el módulo de sucursales en la navegación principal y conectado a sus operaciones de creación y edición.
- Eliminado el fallback de “Módulo en preparación”; cualquier módulo visible ahora resuelve a un panel funcional.
- Añadidas etiquetas accesibles a la navegación para que cada módulo sea identificable por teclado y lector de pantalla.
- Ampliado el QA comercial para cubrir dashboard, configuración, plantillas de impresión, sucursales, proveedores, usuarios, compras, descuentos, cotizaciones, conversiones y notificaciones.
- Conservado el diseño común de referencias: navegación navy, tarjetas blancas, tipografía slate y acciones emerald.

## Verificación

- `npm run build`
- `npm run qa:license`
- `npm run qa:commercial:node22`
- `npm run qa:release`
