# OrbitPOS 2.1.0-alpha.22

## Cambios

- Se agregó `qa:packaged`, que ejecuta el `OrbitPOS.exe` real en un puerto temporal.
- La prueba valida `/api/health`, `/api/meta`, versión del paquete y versión del actualizador.
- El runtime de QA usa una carpeta de datos aislada y la elimina al terminar.
- `qa:production` agrupa las pruebas de licencia, comerciales, runtime empaquetado y release.

## Verificación

- `npm run qa:license`
- `npm run qa:commercial:node22`
- `npm run qa:packaged`
- `npm run qa:release`

## Pendientes antes de producción

- Validar impresora térmica, lector de códigos y balanza físicos.
- Probar instalación limpia y actualización desde GitHub Releases.
- Firmar el instalador con Authenticode y publicar la release oficial.
