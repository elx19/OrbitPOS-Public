# OrbitPOS 2.1.0-alpha.43

## Objetivo

Alinear Usuarios y permisos con la referencia visual manteniendo controles administrativos y recuperación segura.

## Cambios

- Encabezado `Usuarios y permisos`, descripción y CTA `Nuevo usuario`.
- KPIs de usuarios activos, administradores y cajeros.
- Búsqueda por nombre/usuario, filtros por rol y estado, y directorio compacto.
- Se conservan roles, sucursales, contraseñas, preguntas de seguridad, activación y guardado.

## Verificación

- `npm run build`
- Preview responsive de escritorio y móvil pendiente de sesión autenticada en el preview actual.
- QA completo e instalador alpha.43 se ejecutan antes de cerrar esta iteración.
