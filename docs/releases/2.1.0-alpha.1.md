# OrbitPOS 2.1.0-alpha.1

First functional visual-redesign milestone.

## Included

- Shared navy/emerald visual system for the app shell, cards, fields and buttons.
- Compact grouped navigation that keeps the existing module routing intact.
- Updated dashboard card and chart treatment for sales, credits, low stock and receivables.
- Login and first-run wizard surfaces aligned with the approved OrbitPOS references.
- Stored UI references for login, wizard and dashboard under `docs/ui-reference`.

## Verification gate

- `npm run build`
- `npm run qa:commercial`

This is an alpha milestone; production release remains gated on license-generator hardening, module-by-module functional QA and a final packaged build.
