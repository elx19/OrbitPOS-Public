# OrbitPOS 2.1.0-alpha.55

## Shell visual y contexto del negocio

- Se compactó el branding del sidebar para que no domine la pantalla en resoluciones pequeñas.
- Se corrigieron los textos de configuración y asistente: el logo elegido se muestra en login, perfil, tickets y la identidad del negocio, no como bloque de marca del sidebar.
- El módulo de inventario adopta una etiqueta contextual según el tipo seleccionado: colmado, carnicería, embutidos/deli o mixto.
- Se conserva el filtrado de productos, ventas y compras por las categorías permitidas para el negocio elegido.

## Verificación

- Build frontend validado con Vite.
- QA de permisos, aislamiento comercial, display/DPI, licencia y runtime empaquetado se ejecutará sobre el instalador alpha.55.
- La firma Authenticode, las pruebas físicas de dispositivos, la instalación limpia y la actualización real siguen siendo gates externos para producción estable.
