# OrbitPOS 2.1.0-alpha.59

## Sucursales alineadas a la referencia

- Sucursales ahora usa la composición de referencia OrbitPOS: encabezado, acción “Nueva sucursal”, métricas, tabla con búsqueda y panel de detalle.
- El CRUD existente de creación, edición y activación se conserva dentro del panel contextual.
- La pantalla no muestra datos ficticios de ventas; sus métricas provienen de sucursales y usuarios reales de la API.

## Verificación

- `npm run qa:ui` y `npm run build` pasan.
- Se debe regenerar el instalador y ejecutar `npm run qa:production` antes de distribuir esta versión.
- La firma Authenticode, pruebas físicas, instalación limpia y actualización real siguen siendo gates de producción estable.
