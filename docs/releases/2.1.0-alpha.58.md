# OrbitPOS 2.1.0-alpha.58

## Referencia y navegación por negocio

- Se agregó `docs/ui-reference/authoritative/branches-reference.png` para que Sucursales tenga una referencia visual propia.
- El manifiesto visual ahora cubre login, asistente y todos los módulos reales, incluyendo Sucursales.
- Cada perfil de negocio declara sus módulos primarios para usuarios comunes; el sidebar muestra solo ese flujo corto y deja los demás permisos bajo “Más módulos”.
- El QA de UI valida que los módulos primarios de cada perfil existan dentro de sus módulos permitidos y no superen cinco accesos principales.

## Verificación

- `npm run qa:ui` debe pasar referencias y perfiles.
- `npm run build` y `npm run build:electron` deben generar el instalador de esta versión.
- Sigue siendo una versión alpha: firma Authenticode, pruebas físicas, instalación limpia y actualización real continúan siendo gates antes de producción estable.
