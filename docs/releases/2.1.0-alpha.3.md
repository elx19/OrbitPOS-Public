# OrbitPOS 2.1.0-alpha.3

Module reference milestone.

## Included

- Visual references for login, wizard, dashboard, POS, products, purchases and reports.
- A consistent reference direction for the remaining modules: navy navigation, white cards, emerald actions, slate typography and category accents.
- The references are stored in `docs/ui-reference` so implementation and QA can compare each module against the same visual system.

## Verification gate

- `npm run qa:license`
- `npm run build`

The remaining module references and runtime QA continue before the stable production tag.
