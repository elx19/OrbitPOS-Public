# OrbitPOS 2.1.0-alpha.74

## Hito funcional

- La producción deja de bloquearse por firma digital: el instalador se genera sin Authenticode según la decisión del operador.
- Las pruebas físicas de impresora, lector, báscula y cajón quedan fuera de `qa:production`; `qa:hardware` permanece disponible como prueba manual opcional.
- Se agrega `qa:update-feed`, que valida `latest.yml`, `stable.yml`, hashes, tamaños, copias del instalador y descarga HTTP del feed.
- El release verifier exige que el instalador Windows declare y conserve el `.ico` OrbitPOS (`assets/OrbitPOS.ico`).
- La versión se prepara para publicación en GitHub Releases y prueba de actualización desde el feed estable.

## Verificación

- `npm run qa:license`
- `npm run qa:display`
- `npm run qa:assets`
- `npm run qa:ui`
- `npm run qa:update-feed`
- `npm run qa:commercial:node22`
- `npm run qa:packaged`
- `npm run qa:fuses`
- `npm run qa:release`

La firma digital y la validación de hardware físico no son gates de este hito por decisión explícita del operador.
