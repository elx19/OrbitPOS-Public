# OrbitPOS 2.1.0-alpha.66

## Endurecimiento del generador de licencias

- Fuerza el uso de claves Ed25519 para firmar y verificar licencias.
- Agrega `key-info` para auditar algoritmo, tipo y huella pública sin emitir material privado.
- Impide que `keygen` use la misma ruta para la clave privada y la pública.
- Amplía QA con inspección de claves, rechazo de RSA y rechazo de colisión de rutas.

## Verificación

- `npm run qa:license`
- `npm run qa:production`
- Instalador Windows generado y validado con el manifiesto de actualización.

## Pendiente antes de producción

- Completar pruebas físicas con lectores, impresoras, balanzas y cajas reales.
