# OrbitPOS 2.1.0-alpha.60

## Aislamiento al cambiar de negocio

- Inicio, Ventas, Productos, Compras y Reportes se reinician cuando cambia `business_type` para volver a cargar datos filtrados por el perfil activo.
- El contrato de UI verifica ese reinicio y evita que el catálogo de un tipo de negocio quede visible por estado en memoria.
- Release QA comprueba ahora que el instalador NSIS declare una EULA existente.

## Verificación

- `npm run qa:ui` y `npm run build` pasan.
- Se debe regenerar el instalador y ejecutar `npm run qa:production` para validar esta versión.
- Firma Authenticode, pruebas físicas, instalación limpia y actualización real continúan siendo gates de producción estable.
