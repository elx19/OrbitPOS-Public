# OrbitPOS 2.1.0-alpha.9

## Empaquetado Windows

- Configura `signAndEditExecutable: false` para que el empaquetado local no dependa de privilegios de enlaces simbólicos de `winCodeSign`.
- La firma de artefactos se mantiene como responsabilidad del pipeline de release con certificado configurado.
- Corrige `build:unpacked` y `build:portable` para que no intenten publicar un manifiesto de actualización sin un instalador NSIS.

## Verificación

- Rebuild nativo de `better-sqlite3` y `serialport` para Electron 35.7.5.
- Generación de `release/win-unpacked/OrbitPOS.exe`.
- `npm run build:unpacked` completo.
