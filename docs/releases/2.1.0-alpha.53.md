# OrbitPOS 2.1.0-alpha.53

## Permisos por usuario y sidebar contextual

- Se agregó una matriz de permisos persistida por usuario, alineada con la referencia de “Usuarios y permisos”.
- El login y `/api/auth/me` entregan los permisos efectivos de la sesión.
- El sidebar filtra módulos según el tipo de negocio, rol y permiso `view`; los administradores conservan acceso total.
- Los cajeros nuevos reciben por defecto solo sus flujos operativos y pueden recibir permisos adicionales desde la matriz.
- La configuración del negocio mantiene el logo elegido en el login y el perfil del usuario, sin usarlo como bloque de marca del sidebar.

## Verificación

- Migración SQLite compatible con bases existentes mediante `ALTER TABLE` controlado.
- QA comercial valida creación, edición, login, `/api/auth/me` y persistencia de permisos del cajero.
- `npm run qa:production` pasó licencia, hardware, display, QA comercial, runtime empaquetado y verificación de release.
- El instalador incluye `docs/EULA.txt` mediante la configuración NSIS y fue generado como `release/OrbitPOS Setup 2.1.0-alpha.53.exe`.

La firma Authenticode, las pruebas físicas de dispositivos, la instalación limpia y la actualización real siguen siendo gates externos para producción estable.
