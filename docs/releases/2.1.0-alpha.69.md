# OrbitPOS 2.1.0-alpha.69

## Navegación por perfil y tipo de negocio

- AppShell ahora usa `adminPrimaryModules` para los administradores, igual que `primaryModules` para usuarios comunes.
- Los módulos autorizados que no son de uso diario se mantienen accesibles en `Más módulos`, evitando una barra lateral larga y abrumadora.
- La separación continúa dependiendo del perfil de negocio y de los permisos efectivos; el catálogo y las operaciones conservan el filtro por categorías del negocio.

## Verificación

- `npm run qa:ui`
- `npm run build`
- `npm run qa:commercial:node22`
