# OrbitPOS 2.1.0-alpha.16

## License generator endurecido

- Valida que la expiración no sea anterior a la emisión al crear o verificar una licencia.
- Rechaza fechas inválidas en verificación directa del payload.
- Añade `--issued-at ISO` para migraciones y pruebas reproducibles.
- Añade `--key-file ruta.txt` para verificar claves almacenadas sin exponerlas en argumentos del proceso.
- `verify` devuelve código de salida `2` cuando la firma, máquina, versión o vigencia no son válidas.
- Amplía la suite QA con fechas inválidas, expiración invertida, lectura por archivo y código de salida de verificación.

## Verificación

- `npm run qa:license`
- `npm run build`
- `npm run qa:commercial:node22`
- `npm run qa:release`

Esta es una versión candidata funcional; la salida a producción todavía depende de pruebas de hardware, instalación limpia, firma del instalador y publicación del feed.
