# OrbitPOS 2.1.0-alpha.40

## Objetivo

Alinear Créditos y cuentas por cobrar con la referencia visual sin alterar el registro real de abonos.

## Cambios

- Encabezado `Créditos y cuentas por cobrar`, descripción y CTA `Registrar abono`.
- KPIs de saldo total por cobrar, cartera vencida y abonos de hoy.
- La API incluye métricas de abonos del día y cartera con más de 30 días para alimentar la vista.
- Se conservan pagos parciales, métodos divididos, notas, WhatsApp y reimpresión de recibos.

## Verificación

- `npm run build`
- Preview responsive de escritorio y móvil.
- QA completo e instalador alpha.40 se ejecutan antes de cerrar esta iteración.
