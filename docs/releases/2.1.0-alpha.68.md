# OrbitPOS 2.1.0-alpha.68

## Viewport y selector de logo

- El shell autenticado usa `100dvh`, limita la altura del frame al viewport y mantiene el scroll dentro del módulo activo; la navegación lateral conserva su propio scroll cuando el monitor es corto.
- Electron ajusta los bounds restaurados antes de maximizar y vuelve a publicar las métricas de DPI/área de trabajo al cambiar de monitor.
- El selector de logo de Electron convierte PNG, JPG, WEBP, BMP e ICO a `data:` URL con límite de 4 MB. El mismo formato se conserva en login, perfil, asistente y configuración.
- Los backups ahora incluyen también logos guardados como `data:` URL, además de rutas de archivo heredadas.

## Verificación

- `npm run qa:assets`
- `npm run qa:display`
- `npm run qa:ui`
- `npm run build`
