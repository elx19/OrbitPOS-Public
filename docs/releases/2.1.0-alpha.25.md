# OrbitPOS 2.1.0-alpha.25

## Cambios

- Las operaciones POST del wizard quedan abiertas solo durante la configuración inicial.
- Después de completar el wizard, detección, pruebas y lecturas de impresora, lector y báscula requieren sesión de administrador.
- La reconfiguración del sistema exige sesión de administrador y el frontend envía el token activo.
- El POS envía la sesión al leer báscula o lector serial.
- La QA comercial verifica que el hardware no pueda consultarse sin autenticación después del setup.
- El viewport, la altura, el zoom y el `devicePixelRatio` ajustan la densidad visual automáticamente.
- En pantallas pequeñas la navegación se convierte en una barra inferior desplazable.
- El tipo de negocio seleccionado controla el catálogo visible y bloquea categorías ajenas en el backend.

## Verificación

- `npm run qa:hardware`
- `npm run qa:license`
- `npm run qa:commercial:node22`
- `npm run qa:packaged`
- `npm run qa:release`
