# OrbitPOS 2.1.0-alpha.46

## Objetivo

Alinear Licencia con la referencia visual manteniendo la activación, renovación y diagnóstico existentes.

## Cambios

- Encabezado `Licencia` y tarjeta verde de estado activo.
- Panel de activación con machine ID, clave y acción principal.
- Historial de activaciones en tabla compacta.
- Diagnóstico de seguridad con licencia, integridad, conexión, hardware y compatibilidad.
- Se conservan validación de licencia, renovación, historial local, alertas y soporte comercial.

## Verificación

- `npm run build`
- QA completo e instalador alpha.46 se ejecutan antes de cerrar esta iteración.
