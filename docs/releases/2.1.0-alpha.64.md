# OrbitPOS 2.1.0-alpha.64

## Navegación administrativa por tipo de negocio

- Colmado, Carnicería y Embutidos muestran cinco flujos principales apropiados para su operación.
- Los módulos adicionales autorizados permanecen disponibles en «Más módulos».
- Mixto conserva la navegación administrativa amplia para cubrir las operaciones combinadas.
- El contrato de UI valida que los módulos primarios administrativos existan dentro del perfil autorizado.

## Verificación

- QA visual y funcional de login, asistente, navegación responsive, Ventas y catálogo inicial.
- QA de producción, licencia y release ejecutado contra el instalador generado para Windows.
