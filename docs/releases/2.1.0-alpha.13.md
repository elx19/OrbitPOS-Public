# OrbitPOS 2.1.0-alpha.13

## Alineación visual completa

- Se adopta el set de 19 imágenes entregadas por el usuario como referencia autoritativa en `docs/ui-reference/authoritative`.
- Se rediseña el shell común de la aplicación: barra lateral navy plana, encabezado con búsqueda, negocio activo, usuario, notificaciones, breadcrumbs y estados.
- Se actualizan login y wizard con la identidad OrbitPOS, logo sin fondo, verde emerald, pasos visibles y composición de dos columnas.
- Se normalizan los nombres de navegación para que coincidan con los módulos de las referencias: Ventas, Productos e inventario, Créditos y cuentas por cobrar, Usuarios y permisos, Ayuda y soporte, entre otros.
- Productos e inventario incorpora filtros visuales por Abarrotes, Carnes y Embutidos.

## Funcionalidad verificada

- La QA comercial valida venta de productos por unidad y por peso en las tres categorías y comprueba el descuento de inventario.
- El generador de licencias mantiene verificación de máquina, versión mínima, vigencia y claves mensuales.
- La verificación de release exige también las 19 referencias autoritativas para evitar publicar una versión visualmente incompleta.

## Verificación

- `npm run build`
- `npm run qa:license`
- `npm run qa:commercial:node22`
- `npm run build:electron`
- `npm run qa:release`

Las pruebas físicas de impresora térmica, lector de códigos, báscula, instalación limpia, actualización desde feed productivo y firma Authenticode continúan siendo gates obligatorios antes de producción.
