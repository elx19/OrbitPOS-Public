# OrbitPOS 2.1.0-alpha.32

## Objetivo

Alinear el módulo de caja con la referencia visual manteniendo sus operaciones reales.

## Cambios

- Encabezado estable “Caja” y descripción operativa de la referencia.
- Estado abierto/cerrado e historial conservados como indicadores de trabajo.
- Se mantienen apertura, cierre, arqueo, notas, historial y reimpresión de comprobantes.

## Verificación

- Build Vite completado correctamente.
- Navegador a 1920×1080: módulo `cash`, encabezado y ausencia de overflow horizontal verificados.
- QA de producción debe ejecutarse sobre el instalador alpha.32 antes de publicar.
