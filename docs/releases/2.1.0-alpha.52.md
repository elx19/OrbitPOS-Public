# OrbitPOS 2.1.0-alpha.52

## Ventas sin desbordamiento vertical

- El workspace del POS usa la altura disponible del renderer en escritorio.
- Se eliminaron las alturas mínimas rígidas que empujaban “Registrar venta” fuera de una pantalla de 900px.
- La cuadrícula mantiene las dos columnas de la referencia y limita el desplazamiento a listas y formularios internos.
- La vista fue verificada en ejecución a 1536×900 con un usuario cajero.

## Verificación

- Login de QA aislado y menú de perfil.
- Sidebar de usuario común: Inicio, Ventas, Clientes, Caja y “Más módulos”.
- Módulo Ventas cargado y acción principal visible.
- `npm run qa:production` con secreto de licenciamiento definido fuera del repositorio.

La firma Authenticode, las pruebas físicas de dispositivos, la instalación limpia y la actualización real siguen siendo gates externos para producción estable.
