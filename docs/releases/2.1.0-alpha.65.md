# OrbitPOS 2.1.0-alpha.65

## Login adaptable a la pantalla

- El login calcula su altura con `100dvh` y conserva la composición visual de referencia.
- En escritorios bajos, la tarjeta se ajusta automáticamente y evita el corte inferior o el scroll externo.
- La prueba de contrato UI verifica que el comportamiento de viewport permanezca presente.

## Verificación

- Login visual verificado en un viewport de 1280×720.
- QA completo de licencia, hardware, display, UI, comercial, runtime empaquetado y release.
