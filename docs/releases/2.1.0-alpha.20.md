# OrbitPOS 2.1.0-alpha.20

## Cambios

- El control de release valida `latest.yml` y `stable.yml` tanto en `release/` como en los feeds estático y de servidor.
- Se comparan versión, nombre de archivo, ruta, SHA-512, tamaño y `blockMapSize` contra el instalador generado.
- Se verifica que las copias del instalador y del blockmap publicadas en ambos feeds sean idénticas a los artefactos locales.

## Validación

- `npm run qa:release`
- `npm run qa:license`
- `npm run qa:commercial:node22`
- `npm run build:electron`

## Pendientes antes de producción

- Validar impresora térmica, lector de códigos y balanza físicos.
- Probar instalación limpia y actualización desde GitHub Releases.
- Firmar el instalador con Authenticode y publicar la release oficial.
