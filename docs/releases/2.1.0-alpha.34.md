# OrbitPOS 2.1.0-alpha.34

## Objetivo

Reducir la carga visual de la navegación y asegurar que cada tipo de negocio opere únicamente con sus categorías permitidas.

## Cambios

- Usuarios comunes ven cuatro flujos principales: Inicio, Ventas, Caja y Clientes.
- Créditos, Devoluciones, Notificaciones y Ayuda siguen disponibles desde “Más módulos”.
- Se centralizó la resolución del perfil de negocio en backend.
- POS y Compras rechazan productos fuera de las categorías del negocio activo aunque se envíe el ID directamente a la API.
- Dashboard y Reportes filtran productos, inventario y unidades vendidas según el perfil activo.

## Verificación

- Build Vite completado correctamente.
- QA comercial valida catálogo, POS y Compras sin mezcla entre Carnicería y categorías ajenas.
- Se mantiene la validación responsive y la navegación compacta por rol.
