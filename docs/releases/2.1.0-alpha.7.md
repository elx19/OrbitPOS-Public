# OrbitPOS 2.1.0-alpha.7

## Ejecución local reproducible

- `npm run dev:backend` inicia el backend con Node 22.12.0 para evitar el choque ABI de `better-sqlite3` en equipos con Node 24.
- Se conserva `npm run dev:backend:watch` para entornos donde Node 22 ya está seleccionado.

## Verificación

- `npm run build`
- `npm run qa:license`
- `npm run qa:commercial:node22`
