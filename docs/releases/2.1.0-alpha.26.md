# OrbitPOS 2.1.0-alpha.26

## Cambios

- El generador exige un secreto privado de al menos 32 caracteres.
- `decode` y `verify` limitan el tamaño de claves y rechazan esquemas de licencia no soportados.
- Los archivos de secreto se limitan a 16 KB y las claves a 32 KB.
- Los comandos con `--json` devuelven errores estructurados para integración con procesos comerciales.
- Se mantienen las mejoras responsive, de perfiles de negocio y de protección del wizard de `alpha.25`.

## Verificación

- `npm run qa:license`
- `npm run qa:hardware`
- `npm run qa:commercial:node22`
- `npm run qa:packaged`
- `npm run qa:release`

## Pendientes antes de producción

- Validar protocolos, baud rate y terminadores con los dispositivos físicos del cliente.
- Probar instalación limpia y actualización desde GitHub Releases.
- Firmar el instalador con Authenticode y publicar la release oficial.
