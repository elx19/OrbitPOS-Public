# OrbitPOS 2.1.0-alpha.51

## QA de adaptación de pantalla

- La lógica de ajuste de ventana se aisló en `shared/display-layout.js` para que Electron y las pruebas usen la misma regla.
- Se cubren monitores pequeños, monitores secundarios con coordenadas negativas y ventanas restauradas fuera del área visible.
- `qa:production` ahora incluye `qa:display` como gate automático.

## Verificación

- `node --check electron/main.js`
- `npm run qa:display`
- `npm run build`
- `npm run qa:production` con secreto de licenciamiento definido fuera del repositorio.

La firma Authenticode, las pruebas físicas de dispositivos, la instalación limpia y la actualización real siguen siendo gates externos para producción estable.
