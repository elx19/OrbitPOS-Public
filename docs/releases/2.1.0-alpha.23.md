# OrbitPOS 2.1.0-alpha.23

## Cambios

- La báscula ahora puede devolver una lectura real desde el puerto serial.
- Se interpretan lecturas en kilogramos, gramos, libras y onzas, con conversión normalizada a kg.
- El POS muestra `Leer bascula` en productos configurados como venta por peso y aplica el peso leído al carrito.
- La lectura desactivada y el parser de formatos seriales quedaron cubiertos por QA automatizada.
- Se eliminó una etiqueta visual ambigua de créditos que decía “Monto en preparación”.

## Verificación

- `npm run qa:hardware`
- `npm run qa:license`
- `npm run qa:commercial:node22`
- `npm run qa:packaged`
- `npm run qa:release`
