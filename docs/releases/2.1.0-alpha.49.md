# OrbitPOS 2.1.0-alpha.49

## Detección dinámica de pantalla en Electron

- Electron expone métricas de monitor, área de trabajo y factor DPI al renderer.
- La aplicación actualiza esas métricas al redimensionar, mover, maximizar o restaurar la ventana.
- También reacciona cuando se agrega, retira o cambia la escala de un monitor.
- El listener queda expuesto de forma segura mediante `contextBridge`, sin habilitar Node.js en el renderer.

## Verificación

- `node --check electron/main.js`
- `node --check electron/preload.js`
- `npm run build`
