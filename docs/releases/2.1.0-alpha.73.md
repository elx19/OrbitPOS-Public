# OrbitPOS 2.1.0-alpha.73

## Licencia alineada al flujo de referencia

- Se ajustó la pantalla de Licencia al patrón visual de OrbitPOS: estado, activación, historial y diagnóstico en una composición de dos filas.
- La demo se identifica honestamente como `Demo activa`; la activación real conserva su estado `activa`.
- El ID de máquina ahora se puede copiar y confirma visualmente el resultado.
- El historial muestra fecha, equipo, serial/evento y estado con datos reales de la base local.
- El diagnóstico distingue estados correctos de alertas de integridad, conexión, hardware y reloj.
- Se conservó la activación ORB3/Ed25519, la validación ORB2 heredada y el acuerdo EULA declarado en NSIS.

## Verificación

- `npm run qa:license`
- `npm run qa:ui`
- `npm run build`
- QA visual de navegador: Licencia en escritorio, con paneles de estado, activación, historial y diagnóstico.
