# OrbitPOS 2.1.0-alpha.35

## Objetivo

Alinear Inicio/Resumen de negocio con la referencia visual y conservar un acceso operativo directo al punto de venta.

## Cambios

- Encabezado “Resumen del negocio” con periodo visible.
- KPIs con iconografía y datos reales: ventas de hoy, transacciones, inventario bajo y cuentas por cobrar.
- Acceso “Nueva venta” que abre el POS real.
- Gráfica semanal y paneles de productos, últimas ventas y cuentas por cobrar.
- El backend expone el conteo de transacciones del día sin alterar las métricas existentes.

## Verificación

- Build Vite completado correctamente.
- Navegador a 1920×1080: Inicio sin overflow horizontal.
- Acción “Ir a Ventas” verificada: navega al módulo `pos`.
