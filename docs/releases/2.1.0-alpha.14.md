# OrbitPOS 2.1.0-alpha.14

## Iconografía y pantallas iniciales

- Se incorporan los cuatro iconos transparentes entregados para Colmado, Carnicería, Embutidos/Deli y Mixto.
- Las tarjetas del wizard usan el arte original y el login incorpora el icono de colmado en su escena comercial.
- Login y Configuración inicial replican la composición de las referencias: panel navy, marca OrbitPOS, acceso centrado, licencia, pasos, tipos de negocio, moneda y venta por peso.
- El tipo de negocio y `sellsByWeight` se guardan en la configuración persistente del wizard.

## Verificación

- `npm run build`
- `npm run qa:license`
- `npm run qa:commercial:node22`
- `npm run build:electron`
- `npm run qa:release`
