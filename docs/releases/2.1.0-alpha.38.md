# OrbitPOS 2.1.0-alpha.38

## Objetivo

Alinear el módulo de Devoluciones con la referencia visual y conservar el flujo real de reembolso, reintegro al inventario y reimpresión.

## Cambios

- Encabezado, descripción, CTA `Nueva devolución` y tarjetas KPI de devoluciones de hoy, monto devuelto y pendientes.
- Historial filtrable con factura, cliente, productos, motivo, monto, estado y fecha.
- Panel `Procesar devolución` con búsqueda de factura, resumen del cliente, productos, cantidades, reintegro al inventario, motivo y métodos de reembolso.
- Reimpresión de la nota conservada desde cada fila del historial.
- La API expone los nombres de productos asociados para que el historial mantenga contexto sin duplicar consultas en el frontend.

## Verificación

- `npm run build`
- Verificación responsive del módulo en escritorio y viewport móvil mediante el preview local.
- QA comercial, empaquetado y release pendientes de ejecutarse después de generar el instalador alpha.38.
