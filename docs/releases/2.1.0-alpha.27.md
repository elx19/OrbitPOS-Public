# OrbitPOS 2.1.0-alpha.27

## Alcance

- Revisión visual de la shell autenticada según las referencias OrbitPOS: sidebar navy compacto, superficies blancas, acciones emerald, encabezado de sucursal y tarjetas con radios/bordes consistentes.
- Navegación por rol: los usuarios operativos solo reciben módulos comunes; los administradores ven una navegación primaria y un grupo colapsable de módulos administrativos.
- Aislamiento por tipo de negocio mediante perfiles compartidos y filtros de categorías/productos para colmado, carnicería, embutidos/deli y mixto.
- Adaptación responsive para teléfono, tablet, escritorio y pantallas amplias; Electron expone escala DPI, área de trabajo y tamaño físico al frontend para elegir métricas de layout.
- Licencias ORB3 firmadas con Ed25519, clave pública distribuida con la aplicación y `license-generator` con comando `keygen`, generación y verificación mediante clave privada externa.

## Validación ejecutada

- `npm run build`
- `npm run qa:license`

## Estado

Alpha funcional. Antes de producción todavía requiere validación de instalador/actualización en Windows limpio, hardware real de lector/balanza/impresora, firma del instalador y prueba comercial con una clave de licencia emitida fuera del repositorio.
