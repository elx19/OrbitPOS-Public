# OrbitPOS 2.1.0-alpha.70

## Ventas alineadas a la referencia

- Se incorporó la barra de escaneo/código y selección de cliente junto al carrito.
- El código `DEMO-ABA-001` agrega `Arroz Selecto 5 lb` y recalcula los totales mediante el flujo real de ventas.
- La acción principal ahora se presenta como `Cobrar` y continúa conectada al registro real de la venta.
- Se mantuvieron las categorías y el catálogo contextualizados al tipo de negocio seleccionado.
- El shell conserva el contenido dentro del viewport dinámico, sin overflow documental en 1280×720.
