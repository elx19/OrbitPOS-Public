# Recursos visuales de OrbitPOS

- `OrbitPOS.ico`: icono de la aplicación de escritorio.
- `icon.ico`: recurso alternativo para empaquetado.
- `logo.png`: identidad visual de OrbitPOS.
- `orbitpos-logo.png`: marca principal OrbitPOS con hoja verde, usada en login, wizard y navegación.
- `orbitpos-license.png`: icono de activación con llave y escudo, usado en licencia y seguridad.
- `business-types/`: iconos transparentes de Colmado, Carnicería, Embutidos/Deli y Mixto usados en el wizard y el login.

Estos archivos son recursos de interfaz y empaquetado. No deben contener certificados, tokens, claves privadas ni datos de clientes.
